# 迷惑メール対策キット(Gmail向け)

迷惑メールが多すぎて困っている方のための、実用的な対策セットです。
「今すぐできる設定」から「自動化スクリプト」まで、段階的に導入できます。

## 構成

| ファイル | 内容 |
|---|---|
| [docs/gmail-spam-guide.md](docs/gmail-spam-guide.md) | Gmailの迷惑メール対策ガイド(手動設定の手順) |
| [filters/gmail-filters.xml](filters/gmail-filters.xml) | Gmailにインポートできるフィルタのテンプレート |
| [apps-script/spam-cleaner.gs](apps-script/spam-cleaner.gs) | 迷惑メールを自動で整理する Google Apps Script |

## まず最初にやること(5分)

1. **迷惑メール報告を活用する**
   届いた迷惑メールは削除ではなく「迷惑メールを報告」ボタンで報告してください。
   Gmailの学習フィルタが賢くなり、同種のメールが自動でブロックされるようになります。

2. **配信停止(unsubscribe)を使い分ける**
   - 正規の企業からのメルマガ → メール上部の「メーリングリストの登録解除」リンクで解除
   - 心当たりのない怪しいメール → **配信停止リンクは絶対に押さない**(アドレスが有効だと知らせてしまいます)。「迷惑メールを報告」で対応。

3. **フィルタで自動振り分け**
   `filters/gmail-filters.xml` をインポートすると、典型的な迷惑メールパターンを自動でゴミ箱に送るフィルタが設定されます(下記手順参照)。

## フィルタのインポート手順

1. Gmailを開く → 右上の歯車 → **すべての設定を表示**
2. **フィルタとブロック中のアドレス** タブを開く
3. 一番下の **フィルタをインポート** をクリック
4. `filters/gmail-filters.xml` を選択してアップロード
5. 内容を確認して **フィルタを作成**

> インポート前に `gmail-filters.xml` を開いて、自分の状況に合わせてキーワードやドメインを編集してください。

## 自動化スクリプトの導入手順

`apps-script/spam-cleaner.gs` は、ブロックしたい送信者・キーワードのメールを毎日自動でゴミ箱へ移動し、週次でレポートを送ってくれるスクリプトです。

1. [script.google.com](https://script.google.com) を開き、**新しいプロジェクト** を作成
2. `spam-cleaner.gs` の中身をエディタに貼り付け
3. ファイル冒頭の `CONFIG`(ブロックしたい送信者・キーワード)を自分用に編集
4. 関数 `setupTriggers` を1回実行(初回は権限の承認が必要)
5. 以後、毎日自動で実行されます

## それでも減らない場合

`docs/gmail-spam-guide.md` の「根本対策」セクションを参照してください。
メールエイリアス(`avalue.create+shopping@gmail.com` のような `+` 付きアドレス)の活用や、
使い捨てアドレスサービスの利用など、今後迷惑メールを増やさないための方法をまとめています。
