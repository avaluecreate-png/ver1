# しゃべくりパーティー 告知画像 生成プロンプト集

対象：Gemini（画像生成）／ChatGPT（画像生成）／Canva AI など
誘導先：https://pd7.jp/shabekuri-party/

---

## 使い方のコツ（先に読んでください）

1. **日本語の文字は崩れやすい**：まず「④ 文字なし背景版」で世界観の背景を作り、文字はCanvaで乗せるのが一番きれいに仕上がります。①〜③は文字入りで一発生成を狙う版です。
2. **実在の人物の顔はAIに描かせない**：翔さん・Jさんの顔をAIで生成すると別人になり、肖像の扱いとしても問題があります。人物は **ご本人の写真（使用許可を取ったもの）をCanvaで合成** し、AIにはシルエットか後ろ姿までを描かせてください。
3. 気に入った1枚ができたら「この画像と同じトーン・配色で、サイズだけ〇〇に変えて」と続けて頼むと、3媒体の統一感が出ます。

## 共通：世界観の指定（すべてのプロンプトの先頭に貼る）

```
【世界観】
高級ホテルのボールルームで開かれる、特別な夜の祝賀パーティー兼講演会の告知ビジュアル。
テーマは「空気を変える"型"」と「感謝と継承」。

・舞台：ハイアット リージェンシー東京の大宴会場。シャンデリア、深いネイビーの空間、ステージに差し込む一筋のゴールドのスポットライト
・象徴モチーフ：ステージ中央のイーゼルに立てた大きなフリップチャート（白い紙に手書きの線や矢印）。スライドではなく「その場で書いて語る」スタイルの象徴
・高揚感：客席のシルエットが前のめりになり、ステージに視線が集まる瞬間。舞い上がる金の紙吹雪、ボケた光の粒
・祝祭感：さりげないバースデーのニュアンス（シャンパンゴールドのリボン、小さな光の粒）。子どもっぽい風船やケーキはNG
・プレミアム感：「PREMIUM TICKET」のような上質なチケット／招待状のモチーフ

【トーン】
配色：ディープネイビー（#0B1633）×シャンパンゴールド（#D4AF37）×アクセントに情熱のレッド（#C8102E）を少しだけ
質感：映画のポスターのようなシネマティックな光、コントラスト強め、上質・洗練・ワクワク
避けるもの：安っぽいセミナー広告感、原色の多用、ごちゃごちゃした装飾、クリップアート、実在人物の顔の描写
```

## ① Facebook投稿用（縦 1080×1350px／4:5）

```
（共通の世界観をここに貼る）

【用途】Facebookフィード投稿用の告知画像。スクロール中に一瞬で手が止まるインパクト重視。
【サイズ】1080×1350px（縦長 4:5）

【構図】
・上部60%：ステージとスポットライト、中央にフリップチャート。ステージ上に話し手のシルエット（顔は描かない、後ろ姿または逆光シルエット）
・下部40%：ネイビーのグラデーションの上に文字情報のスペース

【入れる文字（大きい順）】
1. メインコピー（最大・金色の明朝体）：「空気を変える"型"がある。」
2. サブコピー：「4人のセミナーから、10万人動員へ。」
3. 登壇者：「しゃべくり社長 川瀨翔 × Mr.J」
4. 日時・会場：「10.9 FRI 17:00–21:00｜ハイアット リージェンシー東京」
5. バッジ（円形・金縁）：「定員300名」「10大特典＋1day合宿付き」

【文字デザイン】メインは上品な明朝体（金の箔押し風）、情報部分は読みやすいゴシック体（白）。文字は最大5要素まで、詰め込みすぎない。
```

## ② LINE配信用（正方形 1040×1040px／リッチメッセージ）

```
（共通の世界観をここに貼る）

【用途】LINE公式アカウントのリッチメッセージ（タップで申込ページへ遷移）。スマホの小さな画面で一瞬で読めることが最優先。
【サイズ】1040×1040px（正方形）

【構図】
・背景：スポットライトが当たるステージと、手前に浮かぶ金縁の「PREMIUM TICKET」風チケット
・チケットの上に文字情報を配置
・画面下部の約15%に、ボタン風の帯（赤 #C8102E）を配置

【入れる文字】
1. メイン（大・金）：「恩人ふたりに、会いに行こう。」
2. サブ（白）：「しゃべくり社長 川瀨翔 × Mr.J」
3. 情報（白）：「10/9(金) 17:00｜ハイアット リージェンシー東京」
4. 価格（金・強調）：「参加費 15,000円」
5. 下部ボタン（白文字）：「詳細・お申込みはこちら ▶」

【注意】文字は大きめ。スマホで読めない小さな文字は入れない。要素は5つまで。
```

## ③ メルマガ用ヘッダー（横長 1200×400px）

```
（共通の世界観をここに貼る）

【用途】メールマガジン冒頭のヘッダー画像（メール内で横幅600px表示）。開封直後に「特別な案内だ」と伝わる招待状のような雰囲気。
【サイズ】1200×400px（横長 3:1）

【構図】
・左側2/3：文字エリア（ネイビー背景に金の細いフレーム、招待状風）
・右側1/3：スポットライトに照らされたフリップチャートとステージ、金の紙吹雪

【入れる文字】
1. 上部の小さな英字（金）：「SPECIAL INVITATION」
2. メイン（金・明朝）：「才能じゃない、"型"だ。」
3. サブ（白）：「しゃべくり社長 川瀨翔 × Mr.J　10.9 FRI｜Hyatt Regency Tokyo」

【注意】横長で小さく表示されるため、文字は3要素のみ。細かい装飾は省く。
```

## ④ 文字なし背景版（Canvaで文字入れ用・おすすめ）

```
（共通の世界観をここに貼る）

【用途】あとからCanvaで日本語の文字とご本人写真を乗せるための背景画像。
【サイズ】1080×1350px、1040×1040px、1200×400px の3種類

【指示】
・文字、ロゴ、数字は一切入れない
・人物の顔は描かない（観客は後ろ姿のシルエットのみ）
・画面の下半分（横長版は左側2/3）は、文字を乗せられるように暗めで情報量の少ない余白にする
・ステージ中央のフリップチャートとゴールドのスポットライトを主役にする
・映画のキービジュアルのようなシネマティックな質感
```
