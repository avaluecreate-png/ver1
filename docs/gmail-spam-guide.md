# Gmail 迷惑メール対策ガイド

## 1. 基本の対策(効果:大)

### 1-1. 「迷惑メールを報告」を必ず使う

迷惑メールを**削除するだけでは学習されません**。
メールを開かずに一覧でチェック → 上部の「!」アイコン(迷惑メールを報告)を押してください。
数週間続けると、Gmailのフィルタがあなた宛の迷惑メールのパターンを学習し、自動でブロックされる量が目に見えて増えます。

### 1-2. 送信者をブロックする

同じ相手から繰り返し届く場合:

1. メールを開く
2. 右上の「︙」メニュー → **「〇〇さんをブロックする」**
3. 以後、その送信者からのメールは自動で迷惑メールフォルダへ

### 1-3. 配信停止リンクの使い分け(重要)

| メールの種類 | 対応 |
|---|---|
| 自分で登録した覚えのあるメルマガ・通販サイト | 件名の横やメール内の「登録解除 / Unsubscribe」で解除してOK |
| 心当たりのない広告・出会い系・当選通知など | **配信停止リンクは押さない**。開かず「迷惑メールを報告」 |

怪しいメールの配信停止リンクを押すと「このアドレスは生きている」と業者に伝わり、**逆に迷惑メールが増えます**。

## 2. フィルタによる自動振り分け(効果:大)

Gmailのフィルタ機能で、特定の条件に合うメールを自動でゴミ箱・アーカイブに送れます。

### 作成手順

1. 歯車アイコン → **すべての設定を表示** → **フィルタとブロック中のアドレス**
2. **新しいフィルタを作成**
3. 条件を入力(例は下記)→ **フィルタを作成**
4. 「削除する」「迷惑メールにしない」などの動作を選択 → 作成

### よく使う条件の例

| やりたいこと | 条件の書き方 |
|---|---|
| 特定ドメインを全部ブロック | From: `*@example-spam.com` |
| 複数ドメインをまとめてブロック | From: `*@spam1.com OR *@spam2.net` |
| 件名のキーワードでブロック | 件名: `当選 OR 無料 OR 副業` |
| 海外からの英語スパム対策 | 含む: `viagra OR casino OR lottery` |
| 自分宛でないメール(BCCスパム)を隔離 | To: `-avalue.create@gmail.com` ※含まないの意味 |

本リポジトリの [filters/gmail-filters.xml](../filters/gmail-filters.xml) にテンプレートがあります。編集してインポートしてください。

## 3. 根本対策 — 今後増やさないために(効果:中〜大)

### 3-1. 「+」付きエイリアスで登録先を分ける

Gmailは `avalue.create+任意の文字@gmail.com` 宛のメールもすべて受信できます。

- 通販サイトには `avalue.create+shop@gmail.com`
- 懸賞・キャンペーンには `avalue.create+camp@gmail.com`

のように使い分けて登録しておけば、**どのサイトからアドレスが漏れたか特定でき**、そのエイリアス宛のメールをフィルタで丸ごとブロックできます。

### 3-2. 使い捨てアドレスを使う

一度しか使わないサイトへの登録には、使い捨てメールサービス(Firefox Relay、DuckDuckGo Email Protection など)の利用を検討してください。

### 3-3. アドレスをネット上に公開しない

SNSのプロフィールや掲示板にメールアドレスをそのまま書くと、収集ボットに拾われます。公開が必要な場合は画像化するか `avalue.create(at)gmail.com` のような表記にしてください。

### 3-4. 流出チェック

[Have I Been Pwned](https://haveibeenpwned.com/) で自分のアドレスを検索すると、過去にどのサービスの情報流出に含まれていたか確認できます。流出したサービスに登録したアドレスは迷惑メールの標的になりやすいので、重要なサービスではパスワード変更も忘れずに。

## 4. 自動化(効果:中、手間の削減:大)

手動対応が追いつかない場合は、[apps-script/spam-cleaner.gs](../apps-script/spam-cleaner.gs) を導入してください。

- ブロックリスト(送信者・キーワード)に一致するメールを毎日自動でゴミ箱へ
- 週1回、何件処理したかのレポートをメールで通知
- ホワイトリスト(絶対に消したくない送信者)にも対応

導入手順は [README](../README.md) を参照。

## 5. 注意事項

- **重要なメールの誤削除に注意**: フィルタで「削除」を選ぶと確認なしでゴミ箱行きになります。最初の数週間は「削除」ではなく「ラベルを付ける+受信トレイをスキップ」で様子を見るのがおすすめです。
- Gmailの迷惑メールフォルダとゴミ箱は **30日で自動完全削除** されます。誤判定がないか、たまに迷惑メールフォルダを確認してください。
- 銀行・宅配業者などを装ったフィッシングメールは、ブロックだけでなく本文中のリンクを**絶対に開かない**ようにしてください。
